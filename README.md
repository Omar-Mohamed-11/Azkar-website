# Azkar Website

A clean and responsive Islamic Azkar website designed to provide a simple and comfortable reading experience. The project focuses on presenting daily Azkar in an organized interface with responsive design for different screen sizes.

## Live Demo

https://omar-mohamed-11.github.io/Azkar-website/

## Features

- Clean and minimal user interface
- Responsive design for desktop and mobile devices
- Organized Azkar sections
- Easy navigation
- Fast and lightweight
- Simple reading experience

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
Azkar-website/

```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Omar-Mohamed-11/Azkar-website.git
```

Open the project folder:

```bash
cd Azkar-website
```

Run the project by opening `index.html` in your browser.
